# Prueba del instalador en una VM limpia (2026-10-17)

TK-160 (issue #122) y TK-242 (#212). `AbastaliaSetup-0.9.0.exe` sin firmar, compilado con Inno Setup 6.7.3 en la misma VM, sobre la rama `tk-160` (basada en `main` 3c94431).

**VM:** Azure `vm-abastalia-test` (`rg-abastalia-test`, eastus2), Windows 11 Pro 24H2 en inglés, Standard_B2s, Trusted Launch con vTPM, **sin BitLocker**, sin IP pública. WebView2 ya venía instalado; SQL Server no. Todo se manejó con `az vm run-command` (como SYSTEM). El instalador corrió en silencio como "PC principal": `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /TYPE=server`, igual que la tarea de actualización.

La primera vez, la descarga del SSEI se quedó colgada dentro del instalador; no se repitió después (una vez más en el instalador, dos en un setup de prueba de Inno y cuatro sueltas). Si vuelve a pasar, el instalador espera sin límite: no hay tiempo máximo para un `Exec`.

## Cómo repetirla

1. Publicar: `pwsh deploy/installer/build.ps1 -Version 0.9.0 -Channel pilot` (sin ISCC solo publica en `artifacts/publish`).
2. Subir `artifacts/publish` y `deploy/` a un contenedor privado (`stabastaliatest…`) y bajarlos en la VM con un SAS de lectura de pocas horas.
3. En la VM (PowerShell como administrador): instalar Inno Setup 6 (`innosetup-6.x.exe /VERYSILENT /SUPPRESSMSGBOXES /SP- /ALLUSERS`, firma de Pyrsys B.V. válida) y compilar: `ISCC /DAppVersion=0.9.0 /DPublishDir=<publish> /DOutputDir=<out> deploy\installer\abastalia.iss`.
4. `AbastaliaSetup-0.9.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /TYPE=server /LOG=setup.log`, mejor desde una tarea programada (si algo se cuelga, no se queda el `run-command`).
5. Comprobar: `sc.exe qprivs Abastalia`, `Get-CimInstance Win32_Service -Filter "Name='Abastalia'"`, el registro `SuperSocketNetLib` de `MSSQL17.ABASTALIA`, los miembros de `sysadmin`, el certificado en 5443, `/health`, la tarea (`schtasks /Run /TN Abastalia\Actualizar`), y por la API (`/api/identity/setup` con un CSR, `/api/identity/sessions`, `/api/settings/health`, `/api/fiscal/certificate`).
6. Desinstalar: `remove-data.ps1 -BackupTo C:\Users\Public\Desktop -ServerDir "C:\Program Files\Abastalia\server"` (con y sin respaldo, y `-NoFinalBackup`), después `unins000.exe /VERYSILENT`.
7. Al terminar: borrar el contenido del contenedor y `az vm deallocate -g rg-abastalia-test -n vm-abastalia-test`.
